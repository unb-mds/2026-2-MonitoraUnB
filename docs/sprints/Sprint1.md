# Sprint 01

**Período:** 14/09/2026 a 19/09/2026

## Descrição

> A Sprint 01 teve como foco principal o planejamento e a documentação inicial do projeto Monitora UnB, estabelecendo uma base para o desenvolvimento do sistema. Durante a Sprint, o grupo trabalhou na elaboração e organização do **Documento de Visão**, **Documento de Requisitos** e **Story Map**, além da definição de decisões técnicas importantes para o projeto.
>
> Também foram discutidas questões relacionadas ao desenvolvimento do Front-end e Back-end, ao uso de TypeScript, ao funcionamento do login da área do professor e a utilização de um plugin. Além disso, foram investigadas possíveis falhas e lacunas técnicas do projeto, buscando alternativas para solucioná-las.

## Objetivos

- [x] Elaborar e organizar o **Documento de Visão** do projeto.
- [x] Desenvolver o **Documento de Requisitos**, definindo as principais necessidades e funcionalidades do sistema.
- [ ] Construir o **Story Map**, organizando as funcionalidades e o fluxo do sistema.
- [x] Definir decisões iniciais relacionadas ao desenvolvimento do Front-end e Back-end.
- [x] Definir o uso de **TypeScript** no projeto.
- [x] Discutir e definir uma alternativa para o login da área do professor.
- [x] Investigar possíveis lacunas, erros e problemas técnicos do projeto.
- [x] Esclarecer dúvidas técnicas com o monitor
- [ ] Esclarecer dúvidas com o cliente.
- [x] Iniciar de forma mais efetiva o desenvolvimento do Front-end e Back-end.
